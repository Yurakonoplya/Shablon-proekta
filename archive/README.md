# Архив

История, а не действующие документы. Здесь лежат объёмные материалы, которые уже не действуют, но которые жалко потерять целиком: большие разборы, отчёты, прежние версии документов, отменённые решения.

Читать как справку — например, чтобы понять, почему в проекте что-то устроено именно так. **Решения отсюда не переносить**: действующие лежат в [project/](../project/). Без нужды сюда не заходить: это не текущее состояние проекта.

## Обязательное правило

Ничто не попадает в архив молча. Положил файл — добавь строку в список ниже: что это, откуда пришло и чем закончилось. Причина решения при этом идёт в [журнал](../project/журнал/README.md), а сюда — сам отработавший материал.

Правило существует ради одного: архив полезен ровно до тех пор, пока по списку понятно, стоит ли открывать файл. Как только приходится открывать всё подряд — архив превращается в свалку, и в него перестают заглядывать.

Однородное складываем вложенной папкой со своим README — как и везде, например `разборы-ошибок/` для post-mortem. Папка заводится, когда в неё есть что положить, а здесь получает одну строку.

Закрытые задачи сюда **не** кладём: их итог — строка в журнале, а не файл. Архив нужен там, где итог в строку не помещается.

## Что здесь лежит

Полезна как справка о том, откуда взялись нынешние правила; действующие — в [CLAUDE.md](../CLAUDE.md) и [project/](../project/).
