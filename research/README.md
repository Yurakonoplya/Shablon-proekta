# Исследования

Здесь то, по чему **решение ещё не принято**: разведка, пробы и замеры, разбор чужих решений, черновики «как это можно было бы сделать».

Главное правило: **принято решение, и его вывод уходит отсюда одной внятной формулировкой туда, где его будут искать**, а файл остаётся здесь обоснованием, «почему решили именно так». Обратной дороги нет: передумали, отменяем решение записью в [журнале](../project/journal/README.md), а не возвращаем вопрос сюда.

Пока вопрос открыт, ему место тут: иначе следующая сессия примет черновик за решение и начнёт на нём строить.

Читать отсюда точечно, по списку ниже, а не подряд: исследование длинное, а короткий вывод из него уже записан там, где его ищут. Имя файла это вопрос, на который исследование отвечает (`payment-provider.md`, а не `research-1.md`).
